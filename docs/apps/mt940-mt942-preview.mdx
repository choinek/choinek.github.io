# MT940/MT942 Preview

I built **StatementLens** — an app for previewing bank statements in MT940 and MT942 formats. You can try it at [mt940.app.chojnicki.pl](https://mt940.app.chojnicki.pl/).

## What the app does

StatementLens is a tool for analyzing bank statements. It lets you:

- **Load files** – drag and drop or click to select (`.sta`, `.mt940`, `.txt`, `.xml`, `.csv`)
- **Paste content** – paste statement text directly (Ctrl+V)
- **Demo mode** – load sample data to see how it works without your own file
- **Source / Result tabs** – preview raw content and parsed output
- **Multilingual UI** – available in Polish, English, German, and French
- **Multiple tabs** – work with several statements at once
